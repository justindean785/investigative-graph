## Cursor Cloud specific instructions

### Project overview
Trace Analyst is an AI-powered OSINT (Open Source Intelligence) investigation platform. It has a Python/FastAPI backend (`backend/server.py`) and a React 19 frontend (`frontend/`) using Shadcn/UI, Tailwind CSS, and React Flow for graph visualization. Data is stored in MongoDB.

**Simplest local setup (Windows / “I don’t know Docker vs Atlas”):** read **[LOCAL_DEV.md](LOCAL_DEV.md)** — pick **Atlas** (no local Mongo) **or** `docker compose up -d` **or** a Windows Mongo service; then it’s always the same two terminals (backend + frontend).

### Services

| Service | Command | Port | Notes |
|---------|---------|------|-------|
| MongoDB | `mongod --dbpath /tmp/mongodb/data --logpath /tmp/mongodb/log/mongod.log --fork --bind_ip 127.0.0.1` | 27017 | Must start before backend |
| Backend | `cd /workspace/backend && uvicorn server:app --host 0.0.0.0 --port 8001 --reload` | 8001 | Requires `MONGO_URL` and `DB_NAME` env vars (loaded from `backend/.env`) |
| Frontend | `cd /workspace/frontend && BROWSER=none yarn start` | 3000 | Requires `REACT_APP_BACKEND_URL=http://localhost:8001` (loaded from `frontend/.env`) |

### Environment files
- `backend/.env` — Must contain `MONGO_URL=mongodb://localhost:27017` and `DB_NAME=trace_analyst`. Optional: `EMERGENT_LLM_KEY` for AI chat features. See `backend/.env.example`.
- `frontend/.env` — Must contain `REACT_APP_BACKEND_URL=http://localhost:8001`. **Production builds require this variable** (`yarn build` will fail if unset). See `frontend/.env.example`.

### CORS (split deployment)
- Set `CORS_ORIGINS` on the backend to a comma-separated list of frontend origins (e.g. `https://your-app.vercel.app,http://localhost:3000`).
- If `CORS_ORIGINS` is `*` (default for local DX), the API sets `allow_credentials=False` because browsers disallow wildcard origins with credentialed requests. Use explicit origins when you need cookies or credentials.

### Non-obvious caveats
- The `emergentintegrations` Python package is a private Emergent platform package not available on PyPI. For local dev without the real package, run `python backend/install_emergent_stub.py` to install a stub. AI chat/suggestion features return a placeholder message without a real `EMERGENT_LLM_KEY`.
- The API requires an `x-api-key` header for all requests. Default key: `trace-analyst-secret-2026`.
- ESLint is integrated into CRA/CRACO (runs during `yarn start` and `yarn build`), not as a standalone config. There is no `eslint.config.js` file.
- Python dependencies install to `~/.local` (user site-packages). Ensure `$HOME/.local/bin` is on `PATH` for CLI tools like `flake8`, `black`, `uvicorn`.

### TestSprite (GitHub Pre-Check)
- The TestSprite GitHub App expects a committed `testsprite_tests/` folder generated by the [TestSprite MCP Server](https://docs.testsprite.com/mcp/getting-started/introduction). If "No tests detected" blocks your PR, either: (1) generate and commit `testsprite_tests/` via MCP, or (2) remove TestSprite Pre-Check from required status checks in GitHub branch protection until tests exist.

### Lint / Test / Build
- **Backend lint**: `python3 -m flake8 backend/server.py --max-line-length=150`
- **Backend tests**: `REACT_APP_BACKEND_URL=http://localhost:8001 python3 -m pytest backend/tests/ -v` (requires backend + MongoDB running)
- **Frontend build**: `cd frontend && yarn build`
- **Frontend dev**: `cd frontend && BROWSER=none yarn start`
