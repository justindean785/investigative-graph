# TestSprite Tests

Generated by TestSprite MCP for the Trace Analyst OSINT investigation platform.

## Structure

```
testsprite_tests/
├── README.md               — This file
├── testsprite.config.json  — TestSprite configuration
├── backend/                — Backend API tests
│   ├── test_auth.py
│   ├── test_investigations.py
│   ├── test_entities.py
│   └── test_allowed_hosts.py
└── frontend/               — Frontend smoke & config tests
    ├── test_craco_allowed_hosts.js
    └── test_api_config.js
```

## Running

### Backend tests (requires running backend + MongoDB)
```bash
python -m pytest testsprite_tests/backend/ -v
```

### Frontend config tests (Node.js)
```bash
node testsprite_tests/frontend/test_craco_allowed_hosts.js
node testsprite_tests/frontend/test_api_config.js
```
